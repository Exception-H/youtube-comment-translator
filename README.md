# 评论译读 · 视频评论中文翻译

版本：1.5.6。一个装进 Chrome 的小工具，帮你看懂 YouTube：把评论和视频标题翻成中文，还能用中文搜到英文视频。（与 YouTube 无隶属关系，非官方。）

## 它做什么

- **评论翻译**：自动把 YouTube 评论译成简体中文，可以中英对照，也可以只看中文。
- **中英双搜**：在 YouTube 搜索框直接输入中文，结果页分成左右两栏：左边是中文关键词搜到的，右边是英文关键词搜到的。
- **英文标题也看得懂**：右栏和首页的英文视频标题会显示中文译名，原标题随时可以展开。
- **窄屏也能用**：窗口较窄时两栏变成标签切换，各自记得上次看到的位置。

不需要注册，不需要 API Key，也不用装其他软件。

## 安装

1. 从 [Releases](https://github.com/Exception-H/youtube-comment-translator/releases/latest) 下载最新的 `评论译读-Chrome-v1.5.6.zip`。
2. 解压。里面有一个 `extension` 文件夹，请保留它，不要删。
3. 打开 Chrome 的 `chrome://extensions`，开启右上角「开发者模式」。
4. 点「加载已解压的扩展程序」，选择那个 `extension` 文件夹。
5. 打开或刷新 YouTube 页面即可。

不要直接把 ZIP 拖进 Chrome。支持 Chrome 109 及以上，主要面向电脑端。

## 已经装过旧版？这样更新

1. 解压新版，用里面的 `extension` 文件夹覆盖原来的 `extension` 文件夹（保留原路径，设置不会丢）。
2. 在 `chrome://extensions` 里点「重新加载」。
3. 刷新 YouTube 页面。

## 怎么用

### 翻译评论

打开任意视频，向下滚动到评论区。评论会自动变成中文。想切换中英对照或只看中文，点扩展图标，在面板里选择「显示方式」。

### 中英双搜

1. 第一次使用时，点扩展图标进入「AI 翻译设置」，找到「中英双搜」，点「授权中英双搜」，允许访问即可。不需要填任何 Key。
2. 回到 YouTube，在搜索框输入中文（例如「Windows 11 卡顿怎么解决」）并回车。
3. 结果页会分成两栏，左右各自滚动、各自加载更多。右栏视频标题显示中文译名，点「查看英文原标题」可以看原文。

只想看普通搜索结果时，点页面右上角的「中英双搜」开关关掉即可，马上恢复 YouTube 原来的结果。

### 首页标题

打开 YouTube 首页或订阅页，英文视频标题下方会自动出现一行中文译名。已经含中文的标题不会重复翻译。

## 常见问题

**要花钱吗？**
不用。默认使用免费的翻译服务，不需要填写付款信息。免费服务可能限流或临时不可用，稍等再试即可；插件不会自动改用收费服务。

**需要填 API Key 吗？**
默认的用法不需要。只有你自己选择其他付费 AI 服务时，才需要在设置里填写那家服务自己的 Key。

**以前配过其他翻译服务，升级后还能用吗？**
能。升级不会改动你已有的配置，也不会替你切换服务。想用新的免费方式，手动选一下对应预设即可。

**右栏没出结果怎么办？**
先点右栏里的「重试」。如果提示需要授权，到设置页点「授权中英双搜」。免费服务繁忙时也会暂时失败，过一会儿再试。

**翻译不准怎么办？**
可以点评论旁的「重新翻译」再试一次，或在设置里换一个翻译服务。机器翻译对俚语、反讽仍可能出错。

**为什么有时要等一会儿？**
免费服务有使用频率限制，插件会排队逐条处理，避免被服务方拒绝。评论很多时请耐心一些。

## 隐私

翻译时，待翻译的文字会发送到你选择的翻译服务。插件没有开发者服务器，不做统计、广告或追踪。详细说明见 [PRIVACY.md](PRIVACY.md)。
