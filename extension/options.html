AI 接口与语境
B站 Index-Translate · 官方免费公网 API

官方免费公网接口，不用登录、不需要 Key；单条翻译，不与批量合并。默认使用 35B（Index-Translate-35B-A3B），也可改选 9B 或 2B。免费公共接口可能限流，不提供长期可用性承诺（无长期 SLA）。

接口地址固定为 https://index-translate.bilibili.com/v1，模型限定为官方公开的 2B / 9B / 35B-A3B；保存时会请求访问该来源的权限。入门顺序：选择 B站预设 → 保存授权 → 测试。打开本页不会访问外网，也不会向其他服务发送 Key。

OpenRouter 仅免费 · 不付费回退

自动合并最多 6 条评论/请求，按 3.2 秒间隔发送；候选繁忙或译文无效时自动换模型，全局限流则暂停，不切换到付费模型。

自动模式在本机从零价目录挑选通用模型：优先 Nemotron Ultra，其次 Super VL / Lightning，再考虑 Gemma / Xing，并排除安全分类、代码等专用模型；无需你判断原文语言。候选上游繁忙、503 或解析无效时会自动换模型，失败最多 3 次请求、每次至少间隔 3.2 秒，每次尝试都会消耗免费请求；全局限流、每日额度不足、认证或隐私限制会停止，不切换付费模型。固定 :free 模型只调用该模型，不自动切换。刷新后也可选择固定的免费模型；后台会再次核验免费价格。免费模型与上游可用性会变化，不承诺始终通用或所有上游可用。

模型目录只在你点击刷新后获取，不需要 API Key。

硅基流动 · 官方中国站零价

使用硅基流动官方中国站标价 0 元的对话模型，单条翻译、不与批量合并；后台按已保存的 Key 读取官方零价目录并与账户可用模型取交集，不使用 Pro/ 付费模型。价格可能变化，核验失败会停止，不会转为付费。

目录来源：硅基流动官方中国站「模型与价格」中标价 0 元、且当前账户可用的模型交集；这里不凭模型名里有没有「Pro」判断免费，也不会列出付费模型。刷新只读已保存的 Key，需先保存本页配置且没有未保存更改。Qwen 系列会明确关闭思考输出，只取译文；单条请求，不占用 OpenRouter 每日免费次数。

保存硅基流动配置后可刷新账户零价模型；默认 Qwen/Qwen3-8B。

B站 Index-Translate 固定使用官方公网 https://index-translate.bilibili.com/v1；硅基流动仅免费模式固定使用官方中国站 https://api.siliconflow.cn/v1，OpenRouter 仅免费模式固定使用 OpenRouter；其他模式可填基础地址或完整 /chat/completions 地址。公网须 HTTPS，本机 localhost、127.0.0.1 可用 HTTP。

B站预设仅限 Index-Translate-2B / 9B / 35B-A3B（默认 35B）；硅基流动零价模式可直接填写模型名，或从上方候选/刷新结果中选择；OpenRouter 仅免费模式只能从上方列表选择。自定义模式须填写服务实际支持的聊天模型。

B站预设不需要 Key，此字段会隐藏并清空；切出 B站预设后可重新填写，且不会沿用旧服务的 Key。硅基流动与 OpenRouter 都需要各自的 Key；硅基流动账号需按官方要求完成实名。密钥保存在本机扩展存储中，未加密；不要发到聊天中。
